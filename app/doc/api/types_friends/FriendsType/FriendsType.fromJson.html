Factory constructor to create a FriendsType instance from a JSON map. This is typically used to parse API responses into Dart objects.

The method takes a JSON map as input and extracts the relevant fields to create an instance of FriendsType. It also handles the parsing of the decorations field, which is a list of decoration items, and the friend_at field, which is parsed into a DateTime object if it is present in the JSON.

Usage:

final friend = FriendsType.fromJson(jsonData);

Implementation

factory FriendsType.fromJson(Map<String, dynamic> json) {
  // if (kDebugMode) {
  //   print("Parsing FriendsType from JSON: $json");
  // }
  return FriendsType(
    friend_account_id: json['friend_account_id'] as String,
    username: json['username'] as String,
    daily_score: json['daily_score'] as int,
    decorations: (json['decorations'] as List<dynamic>? ?? [])
        .map((item) => Decorations.fromJson(item))
        .toList(),
    friend_at: json['friend_at'] != null
        ? DateTime.parse(json['friend_at'])
        : null,
  );
}
